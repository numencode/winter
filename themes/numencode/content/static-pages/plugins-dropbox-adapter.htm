NumenCode.DropboxAdapter registers a dropbox disk. Anything that writes to a Laravel disk can write to Dropbox: backups, exports, even the media library.

php artisan dropboxadapter:setup

The setup command asks for the app key, opens the authorization link and writes a long-lived refresh token to .env. With PKCE, the app secret is not needed on the server. Short-lived access tokens are renewed automatically.
